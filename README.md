# Progressio

Progressio is a dynamic progress-tracking mobile application tailored for managing personal
projects through the assignment of tasks and keeping track of the same. It offers project tracking,
allowing users to manage individual projects and goals efficiently. Task management is enhanced
with customizable labels ,priorities and deadlines, ensuring timely completion.
Progressio features a visual progress graph that shows percentage completion over time.
The intuitive user interface includes secure registration/login, a user profile, customizable
settings, a detailed to-do list, a comprehensive timeline, and visual progress graphs. Progressio's
comprehensive tools boost productivity and personal project success.

## Features

- Create multiple projects.
- Create tasks for the said projects
- View the timeline of tasks
- Account Management: reset password, edit profile.

- __Create Multiple Projects:__ Upon logging in, users can create multiple projects to manage multiple projects to managetheir various endeavors effectively. Each project can be given a unique name and color allowing for easy identification and organization. It also shows the amount of tasks left tobe completed and a progress bar to show the amount of tasks completed.
